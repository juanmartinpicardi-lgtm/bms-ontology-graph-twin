# Troop D test package: documents for the guided setup

Use these files to test **Projects → Add a building** end to end. Upload them in this order, one per step
(each step also has a "Use the test file" button that loads the same file):

| Step | File | What it is | Real or synthetic |
|---|---|---|---|
| 1 Floor plans | `1_floor_plans.pdf` | Mechanical plans M-101 to M-104 (levels 1–3, roof) | Real public bid drawings |
| 2 Equipment schedules | `2_equipment_schedules.pdf` | M-401, M-301 to M-303: unit schedules and the flow diagrams | Real public bid drawings |
| 3 Sequences of operation | `3_sequences.pdf` | M-304: sequences of operation | Real public bid drawings |
| 4 Controls submittal | `4_controls_submittal.pdf` | Controls submittal: risers, point lists, room schedule, RFIs | Synthetic, made from the answer key |
| 5 BMS export | `5_bms_export.csv` | One row per BMS object, as exported from a BMS | Synthetic, made from the answer key |

Steps 1–3 are pages taken from the public Troop D Crime Lab bid set (source in `data/raw/SOURCES.md`).
Steps 4–5 are generated by `scripts/build_troop_d.py`, which also rebuilds this folder. The answer key is in
`data/ground_truth/troop_d/`.

At step 6 (Review), choose the answer key `troop_d` to see how much the machine got right alone, and how much after
your answers.

**About the score.** The synthetic submittal and BMS export are written from the answer key, so the measures that
rely on them (box rooms, points) look better than they would on a real job. The row "Box room from the floor plan
alone" shows what the real drawings give without that help.

What you should see: 4 floors, 80 rooms, 72 scheduled units, 847 points. The app should also flag real design
issues, for example:

- there is no exhaust fan schedule
- FVAV-15's heating airflow is below its minimum
- some section letters are skipped in the sequences
